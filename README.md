# 微信聊天记录导出工具（macOS）

![把一整段聊天自动滚动截图、识别，整理成一份 Word 文档](docs/cover.jpg)

把电脑微信里**当前打开的会话**导出成 **Word（.docx）** 和 **Markdown（.md）**，
按时间顺序带上聊天文字、图片、时间、系统提示，仿微信左右气泡排版，
方便存档和整理客户需求 / 喂给 AI 分析。

**聊天里发的文件和视频也会一起导出**：微信 4.x 把收到的文件和视频明文存在本地，
本工具把真实文件找回来复制到导出目录旁，并在文档里写清它在微信里的原始位置。
视频还会**自动认出气泡对应的是哪一个 mp4**（按封面比对，不靠猜），
**本机还没下载过的，会自动点开让微信下下来**再一并导出。

- **不解密、不碰数据库、不动 SIP、不改微信**——纯靠"读屏 + 自动滚动截图 + OCR"，最安全。
- 全程**本地离线**，不联网、不上传任何数据。
- 文字用 macOS 原生 OCR 识别，可在 Word 里直接编辑、复制、批注。
- 适用于 Mac 版微信 4.x，在 macOS 26 上开发实测。

## 一、怎么启动

### ✅ 方式 A：下载安装包（最省事，不需要装 Python）

到 [Releases](../../releases) 下载 `WeChatChatExport-x.y.z.dmg`，打开后把 App 拖进
Applications 即可。**不依赖 Python 环境，装完就能用。**

> 安装包只支持 **Apple 芯片（M1 及更新）** 的 Mac。Intel 芯片的 Mac 请用方式 B 从源码运行。

> **首次打开会被系统拦一下**：本 App 没有购买苹果开发者签名（$99/年），
> macOS 会提示「无法验证开发者」。**右键点 App → 打开 → 再点一次「打开」**，
> 之后就能正常双击。这是所有未签名 App 的通例，不是软件有问题。
>
> **首次抓取要授权两项**：系统设置 → 隐私与安全性 →
> **辅助功能** 和 **屏幕录制** 里都勾上「微信聊天记录导出」，然后退出 App 重开一次。
>
> **升级到新版之后又说「缺少辅助功能权限」？** 开关明明还亮着也没用——
> 本 App 没买苹果开发者签名，每次出新版签名都会变，macOS 的权限库记的是
> **旧版那份签名**，新版对不上号，界面上的勾只是旧记录留下的假象。
> 在这两个列表里把那条选中、按下面的 **「−」删掉**，再按 **「+」** 把

>
> 安装版的导出结果存放在 **`~/Documents/微信聊天记录导出/导出结果/`**。

> 想自己打一个安装包：双击 **`打包安装包.command`**，

> 把 **「微信导出」** 都打开，然后回到 App 再点一次「开始抓取」。（只需授权一次）

> 若双击提示"来自身份不明的开发者"：**右键 App → 打开 → 再点打开**，之后就能直接双击。

### 方式 C：备用启动（最稳，用终端已有权限）

### 方式 D：命令行（全量自动，不用手选）
```bash

# 改了解析规则想重出文档？不用重新抓取，直接重解析上次的长图(十几秒)
./.venv/bin/python wxexport.py --from-image _tmp/stitched_full.png --name 客户张三
```

## 二、App 使用流程

1. 在微信里**点开要导出的会话**（客户 / 群）
2. 打开本 App，在主面板上把要的都勾好：
   - **抓取范围**：`整段聊天记录`（自动滚到会话最开头，推荐）／ `从当前位置往下`
   - **导出格式**：Word（.docx）／ Markdown（.md），可只勾一个
   - **图片取原图**（默认勾上）：气泡里那张只有约 320px，放大就糊；勾上会逐张
     点开预览窗把原图要回来（实测 383px → 1920px），图多时会慢一点，
     抓完剪贴板会还原
   - **同时导出聊天里的文件**：把聊天里发的 Word/PDF/PSD/压缩包一并拿出来
   - **同时导出聊天里的视频**：认出每条视频对应本机的哪个 mp4，取出来放进 `视频/`；
     下面还可勾 **「本机还没有的视频，自动点开下载」**（默认勾上）——微信没有
     「只下载不播放」的入口，所以工具会逐条点开、等它下完再按 Esc 关掉
   - 上面两项共用一个**位置**设置：`复制到导出文件夹`（默认，整个夹子可打包转发）
     或 `只记微信原始位置`（不复制、不占空间，文档里写微信本地的绝对路径）
   - **抓完直接导出**：不预览不选区间，抓完立刻出文档（最省事）
3. 点 **「开始抓取」**，微信会自动滚动，**期间别碰鼠标键盘**
4. 想中途停下：按 **⌃⌥⌘ + .（句号）**，或在 Dock 里点开本 App、按红色 **「停止抓取」**
5. 没勾「抓完直接导出」的话，会出现**预览长图**：**点一条消息作「开始」，再点一条作「结束」** →
   只导这一段（不点则导出整段），然后点 **「导出 Word + Markdown」**
6. 结果区会直接列出**这次的文件夹**和里面的内容，点「打开这次的文件夹」即可

> 所有勾选都会记住，下次打开还是上次的设置。

## 三、输出

**每次导出独占一个文件夹**，文档、图片、文件全在里面，整个文件夹可以直接压缩发给别人或归档：

```
导出结果/
  客户张三_0903-2114/           ← 会话名 + 月日-时分
    聊天记录.docx               Word（仿微信气泡排版）
    聊天记录.md                 Markdown（AI 友好）
    图片/    img_001.jpg …      图片（能拿到原图的就是原图，拿不到才退回气泡截图）
             video_001.jpg …    视频封面（直接取微信本地那张，比截图清楚）
    文件/    首页修改.psd …      聊天里发的真实文件
    视频/    视频_001_36秒.mp4 …  聊天里发的视频本体
```

文件夹名带时间戳，所以**重复导出同一个会话不会覆盖上一次的结果**。
文档里的图片和附件都是相对链接（`图片/…`、`文件/…`），整个文件夹搬到哪都点得开。

**文件是怎么找回来的**：微信 4.x 把聊天收到的文件明文存在
`~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/<账号>/msg/file/年-月/`，
保留原始文件名。工具从聊天截图里 OCR 出文件卡片上的文件名，
去这个目录做匹配（能容忍全角括号、`(1)` 重名后缀和个别 OCR 误字），
命中就复制一份到 `_文件/` 并在文档里写上原始路径；没命中就直接标注
「本机没有这个文件（没下载过或已过期）」，绝不瞎猜。

> 注意：**只有在这台电脑上下载过的文件才在本地。** 从没点开过、
> 或超过服务器保存期的文件，磁盘上根本没有，只能保留文件名。
> 聊天里的**图片**在磁盘上是加密的 `.dat`（4.x 新格式），不过不用解密也能拿到原图，
> 见下面「图片怎么拿到原图」。

**图片怎么拿到原图**：气泡里那张是**缩略图**——微信给图片气泡限宽约 160pt，
Retina 下截出来也就 320px 见方，所以早期版本导出的图放大就糊。原图确实是加密的
（`.dat` 以 `07 08 56 32` 开头），但微信自己留了一条明路：在「图片和视频」预览窗里
按 **⌘C**，它会把解好的图写到 `…/temp/RWTemp/年-月/<哈希>.png`，并把这个文件的
路径放上剪贴板。所以工具不解密、也不扫盘，按完 ⌘C 直接问剪贴板要路径。
**实测 383px 的气泡 → 1920px 的原图（线性 5 倍，像素 25 倍）**，11 张图整步 15 秒。

**怎么找到要点的那个气泡**：不靠"一屏屏往上翻着找"。长图就在手里，当前屏幕本来
就是长图的一个切片，把这一帧在长图上滑一遍取最高分（实测匹配 0.96~0.98），就
**量**出了"现在看到的是长图第几行"，气泡在屏幕上的坐标直接算得出来。多数情况下
最后一张图就在当前视口里，**一屏都不用翻**；不在才往回翻，且每翻一屏重量一次、
一露头就点，翻出本次抓取范围就停。早先的版本是盲翻 200 屏＋图像比对找气泡，
会话长的用户会看到它没完没了地翻。

只需要点开**一张**：预览窗的 ← → 是在会话的图片序列里走，所以点开一张之后，
从它出发往两头走、每站按一次 ⌘C 就行。但**不能闷头走到头**——预览序列是整个
会话的历史，往往远多于这次要导出的那段（实测一个工作群，导出只涉及 20 张，
序列里有 600+ 张，"先退到第一张"白走了 200 步、192 秒）。所以每站当场跟还没对上号
的气泡比对，连续 6 站对不上就收手，两头都这么干。扫图期间会连按几十次 ⌘C，
**开工前先存一份用户的剪贴板，收工原样还回去**。

**认哪张原图对应哪条消息**：图像比对(NCC) + 位置线索（←/→ 走的就是会话顺序，
过线的候选里挑离"该轮到谁"最近的那个），另加两道实测踩出来的闸：

- **长宽比**：微信只会把图竖着裁（气泡限高），绝不会把一张扁图显示得更高，所以
  原图不可能比气泡"矮"。踩过一次 493x163 的气泡被配到 1807x112 的原图上，
  导出来完全是另一张图。
- **重叠行数**：比对时统一缩到 48 宽，高度就是长宽比。上面那张扁原图只剩 3 行，
  拿 3x48=144 个像素比出来的分纯属噪声，随便哪张都能过线。

实测一段 51 条消息、7 张图的区间：6 张换成原图且**全部配对正确**，
剩下 1 张被闸拦下、退回气泡截图，**零配错**。取原图整步 9.4 秒。

**视频是怎么认出来的**：视频存在 `…/msg/video/年-月/` 下，
`<哈希>_thumb.jpg` 是气泡里那张封面（消息一到就有），`<哈希>.mp4` 只有**下载过**才有。
文件名是哈希，跟聊天内容对不上号，所以工具拿**长图里的视频气泡**去和磁盘上的封面
逐一做归一化互相关：竖直滑动对齐（气泡里常常只显示封面的一段），
并挖掉正中间那枚微信画上去的播放按钮。实测 466 个视频的库里，
真匹配 **0.989~0.996**，同一条的第二名 0.71~0.95，而真·图片气泡最高只有 **0.770**，
所以 0.93 这条线两边都很空——既不会把图片当成视频，也不会认错人。
时长直接从 mp4 头里读（实测与气泡上显示的 0:15 / 0:36 / 0:53 完全一致）。

**没下载的怎么办**：微信没有「只下载不播放」的入口，所以工具会在**长图拼完之后**
往回翻，把还没下到本机的视频逐条点开、盯着磁盘上的文件长大、不再变化就按 Esc 关掉
预览窗。放在拼图之后做是有讲究的：点开会弹预览窗，关掉后微信有可能把聊天视图挪位置，
那时候长图已经到手，挪了也伤不到结果。到底下下来的是哪一条，**不看「我以为点的是谁」，
而看磁盘上新冒出来的是哪个文件**，所以认错气泡也不会把别人的视频记到这条头上。

导出内容会自动做这些清理：

- 气泡里**因宽度自动折行的句子合并成完整段落**（自己按回车分的行会保留）
- 滚动拼接产生的**重复文字 / 重复时间分隔自动去重**
- 居中的时间戳、"已建群"、撤回提示等**系统消息不再误算成"对方"的发言**
- **群聊**里尽量识别气泡上方的**成员昵称**（识别不到时仍显示"对方"）
- **系统提示**（"XX 邀请你加入了群聊"、"XX 撤回了一条消息"、改群名）会一并保留
- 输入框里的**草稿**不会被当成最后一条消息导出
- 群昵称标签、图片里的文字等**假气泡**会被剔除（按气泡高度判定）

## 四、已知限制

- **文字靠 OCR**：99% 的中文/英文/数字/网址都准，但表情图标、花体字偶有个位数误识别，导出后扫一眼即可。
- **语音转文字**：勾选后会自动右键调用微信自带「转文字」（先确认菜单里有该项才点，误判不会误操作）。属实验功能，较慢，建议先在有语音的会话试跑验证。
- **视频自动下载**会逐条点开播一下再关掉（微信没有只下载不播放的入口），
  视频多、文件大的会话会明显变慢；不想等就把这个勾去掉，文档里仍会写清
  「本机没有这个视频」。单次最多下 30 条、累计 1.5GB 封顶，免得一个几百条视频的
  群聊把硬盘吃满。
- 视频按**封面图**认人，如果一条视频的封面缩略图在本机已经被微信清理掉了，
  那条就认不出来，会按普通图片导出（不会张冠李戴）。
- **群聊昵称**是按屏幕小字标签识别的，偶尔漏识别时该条会显示为"对方"或沿用上一条的名字。
- **很长的会话**滚动抓取会花几分钟；App 里可调「最多滚动屏数」。
- 抓取时微信会被切到前台自动滚动，**期间不要操作电脑**。
  如果中途点了别的窗口，工具会自动把微信抢回前台继续抓；抢不回来会直接报错，
  不会像以前那样把"滚不动"误当成"已经到底"、悄悄只导出半截。
- 微信按块加载历史，长会话滚动时视图偶尔会自己跳一下。工具会回退重新对位；
  实在对不上才在接缝处续接，此时**可能有个别消息重复或缺失**（日志里会写明）。

## 五、技术说明

`前台化微信 → 滚到最新 → 逐屏截图并按像素位移拼成整段长图 → 分片 OCR 提取文字 →
按气泡颜色区分我/对方、识别时间戳/系统消息/群聊昵称、抠出图片 → 渲染成 Word / Markdown`

| 文件 | 作用 |
|------|------|
| `微信导出.app` | 桌面应用（AppleScript 外壳启动下面的 app.py）|
| `app.py` | 图形界面（pywebview，抓取/预览/点选/导出）|
| `engine.py` | 抓取+解析引擎（App 和 CLI 共用）|
| `wechat_ui.py` | 驱动微信（前台化/滚动/截帧/位移匹配/停止控制）|
| `geometry.py` | 定位聊天区 |
| `ocr.py` | macOS Vision OCR（长图分片以保准确度）|
| `parse3.py` | 解析（气泡连通域/时间戳/昵称/去重/折行合并）|
| `render_docx.py` / `render_md.py` | 排版输出 |
| `voice.py` | 语音自动转文字 |
| `paths.py` | 导出目录规划（每次导出一个文件夹）|
| `appdirs_local.py` | 区分源码运行 / 打包运行的可写目录 |
| `打包.spec` / `打包安装包.command` | PyInstaller 打包配置与一键出 DMG |
| `修复权限.command` | 升级后权限对不上号时，一键清掉旧授权记录重来 |
| `wxfiles.py` | 在微信本地目录里按文件名找回真实文件 |
| `wxvideo.py` | 按封面认出视频是哪一个 mp4、自动点开下载、导出时复制 |
| `wximage.py` | 让微信在预览窗里吐出图片原图（⌘C），代替糊掉的气泡截图 |
| `wxexport.py` | 命令行版 |
| `docs/` | README 用到的图片 |
| `导出结果/` | 所有导出的文档和图片 |
| `_tmp/` | 运行时的截图/拼接图等临时文件，可随时整个删除 |

依赖装在 `.venv/`（pyobjc / Vision / scipy / python-docx / Pillow / numpy / pywebview）。

**速度**（实测，一段 157 条消息 / 3 万像素长图的群聊）：
抓取阶段约 **2700 px/秒**，抓取+解析+导出全程约 **63 秒**（最初是 1 分 42 秒）。日志每行都带已用秒数，
一眼能看出慢在滚动还是 OCR。三处关键优化：

| 改动 | 效果 |
|---|---|
